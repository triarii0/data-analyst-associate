## Distribución de dominios (temario de octubre de 2025)

Las 45 preguntas se agrupan en los nueve dominios oficiales. En octubre de 2026 se reequilibró el simulado para que cada dominio reciba su parte de las 45 preguntas según su peso oficial, redondeada a preguntas enteras. Las cinco antiguas preguntas de actualización (tres sobre Genie Spaces, una sobre paneles y una sobre modelado de datos) ahora forman parte de las 45 preguntas calificadas.

| Dominio | Peso oficial | Parte de 45 con ese peso | Preguntas en este simulado |
| ------ | :---: | :---: | :---: |

## Guía de calificación

| Puntuación | Resultado |
| ----- | ------ |
| 36–45 (≥ 80 %) | Excelente |
| 32–35 (70–79 %) | Probablemente aprobado |
| 27–31 (60–69 %) | Cerca del objetivo: se requiere estudio enfocado |
| Menos de 27 (< 60 %) | Se requiere una revisión exhaustiva |

> [!note]
> Databricks no publica un umbral numérico de aprobación para la guía del examen vigente.
