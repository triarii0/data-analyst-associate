| Detalle | Valor |
| ------ | ----- |

## Distribución de dominios (temario de octubre de 2025)

Las 45 preguntas se agrupan en los nueve dominios oficiales. En octubre de 2026 se reequilibró el simulado para que cada dominio reciba la parte correspondiente de las 45 preguntas según su peso oficial, redondeada a preguntas enteras. Las tres antiguas preguntas de actualización de Genie ahora forman parte de las 45 preguntas calificadas. Las preguntas de actualización de paneles y de modelado de datos eran idénticas a las del Examen simulado 1, por lo que aquí se han sustituido por preguntas nuevas.

| Dominio | Peso oficial | Parte de 45 con ese peso | Preguntas en este simulado |
| ------ | :---: | :---: | :---: |
| Ejecución de consultas con Databricks SQL y Warehouses | 20 % | 9 | 9 |
| Creación de paneles y visualizaciones | 16 % | 7.2 | 7 |
| Análisis de consultas | 15 % | 6.75 | 7 |
| Desarrollo, uso compartido y mantenimiento de AI/BI Genie Spaces | 12 % | 5.4 | 5 |
| Comprensión de la plataforma Databricks Data + AI | 11 % | 4.95 | 5 |
| Gestión de datos | 8 % | 3.6 | 4 |
| Protección de datos | 8 % | 3.6 | 4 |
| Importación de datos | 5 % | 2.25 | 2 |
| Modelado de datos con Databricks SQL | 5 % | 2.25 | 2 |
| **Total** | **100 %** | **45** | **45** |

## Guía de calificación

| Puntuación | Resultado |
| ----- | ------ |
| 36–45 (≥ 80 %) | Excelente |
| 32–35 (70–79 %) | Probablemente aprobado |
| 27–31 (60–69 %) | Cerca — se requiere estudio enfocado |
| Por debajo de 27 (< 60 %) | Se requiere una revisión integral |

> [!note]
> Databricks no publica un umbral numérico de aprobación para la guía del examen actual.
