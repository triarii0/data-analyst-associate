# Databricks Data Analyst Associate
## Temas de estudio

La estructura de carpetas siguiente coincide con el esquema oficial de 9 dominios de octubre de 2025. Léala en orden; el `README.md` de cada carpeta contiene el temario de la sección y los conceptos clave.

| Sección                                                                                | Peso | Enfoque |
| -------------------------------------------------------------------------------------- | :----: | :--- |
| [01 — Ejecución de consultas con Databricks SQL y SQL warehouses](./01-executing-queries-databricks-sql-warehouses/README.md) | 20 %   | SQL warehouses, Assistant, combinaciones y operaciones de conjuntos, agregaciones, tablas, viaje en el tiempo, MV frente a tablas de streaming, federación |
| [02 — Creación de paneles y visualizaciones](./02-creating-dashboards-and-visualizations/README.md) | 16 %   | Paneles AI/BI, visualizaciones, parámetros, alertas, programaciones, uso compartido e inserción |
| [03 — Análisis de consultas](./03-analyzing-queries/README.md)                              | 15 %   | Photon, historial y perfil de consultas, caché, historial de Delta, liquid clustering, corrección de consultas |
| [04 — Desarrollo, uso compartido y mantenimiento de AI/BI Genie Spaces](./04-developing-sharing-maintaining-genie-spaces/README.md) | 12 % | Creación, curación, benchmarks, uso compartido y API de Genie Spaces (ahora Genie Agents) |
| [05 — Comprensión de Databricks Data + AI Platform](./05-understanding-databricks-platform/README.md) | 11 % | Componentes de la plataforma, Unity Catalog, Catalog Explorer, Marketplace, conexiones |
| [06 — Gestión de datos](./06-managing-data/README.md)                                     |  8 %   | Conjuntos de datos certificados, etiquetas, linaje, limpieza de datos, tablas y esquemas |
| [07 — Protección de datos](./07-securing-data/README.md)                                     |  8 %   | Privilegios, propiedad, namespace y volúmenes, filtros de filas, máscaras de columnas y PII |
| [08 — Importación de datos](./08-importing-data/README.md)                                   |  5 %   | Carga desde la interfaz, S3 y `COPY INTO`, Auto Loader, Delta Sharing, ingesta por API y Marketplace |
| [09 — Modelado de datos con Databricks SQL](./09-data-modeling-with-databricks-sql/README.md) |  5 %   | Medallion, esquemas estrella/copo de nieve, Data Vault, vistas frente a MV |
